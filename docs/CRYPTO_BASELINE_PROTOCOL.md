# Frozen crypto baseline diagnostic

This is a single new crypto baseline, not a retuning of rejected ETF candidates or a replay of the five advisory analysts. Earlier crypto research already exists in this project. No broker actions or risk policy changes are authorized by this experiment.

BTC-USD and ETH-USD daily OHLCV, January1,2023 through September22,2026, are publicly refreshed from Yahoo Finance. Days are interpreted as UTC bars, including weekends. Check unique ordered complete daily calendars and positive consistent OHLCV. Source is aggregated indicative data, not Alpaca executable quotes; no venue-cross-check has been performed.

Freeze one rule: long if completed close is strictly above its trailing200day arithmetic mean, otherwise flat. First evaluation row is July20,2023 after200warmup rows; its signal executes the following daily open. Second evaluation window begins January1,2025; prior data warms the signal but does not carry positions. Development ends December31,2024. The later reserved historical diagnostic ends September22,2026 and is not pristine confirmation because earlier crypto research has already consumed history. Both windows start flat with$100,000. No parameter search or signal changes after outcomes.

Reuse BacktestEngine.run. Each entry targets12.5% of current portfolio equity, with25% entry gross cap and at most2positions. Shared sizing adjusts for friction/capacity. Positions drift without rebalancing and can exceed25% through appreciation. Spot long only, no leverage, shorting, ATR stops or trailing stops; exit next open when signal is flat. Set hold_bars100000 so the time exit does not affect this sample. The existing3%daily-loss halt blocks/cancels entries and does not force liquidation. Daily bars cannot model real-time enforcement. Terminal liquidation uses last completed close with modeled costs. This research configuration is not adopted for paper/live execution.

Run12distinct scenarios: two windows × crypto baseline and approximately25% initial buy-and-hold basket × zero friction,25bps taker fee plus5bps one-way impact, and25bps fee plus15bps impact. Buy-and-hold uses constant-long signals in the same engine, enters next open after first evaluation row and terminal-liquidates. Both report exposure differences; this is not a volatility-matched alpha test. No cash interest. Annualization365. Costs are assumptions, not calibrated fills; flat25bps ignores volume discounts and approximates buy-side crypto fees as USD fees. Zero friction is a counterfactual, not a realistic execution claim. Recurring business overhead is unknown.

Freeze code/data hashes before running; preserve protocol, exact raw input snapshots, complete daily ledgers, orders, trades and independent cash/holdings reconstruction. All outcome windows and cases are retained. Use one sequential worker, at least1GiB free initially and512MiB during run; expected outputs below30MB. No random draws. Later prospective validation remains required; no promotion threshold is crossed by this diagnostic alone.
